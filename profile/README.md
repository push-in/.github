**The native runtime for PHP.**<br>
Servers, desktop and mobile from one PHP codebase. No Electron. No Node. No browser in the middle.

[Docs](https://push-in.github.io/pam-docs/introduction/) · [Quick start](https://github.com/push-in/pam#quick-start) · [Ecosystem](https://github.com/push-in/pam#ecosystem) · [Discussions](https://github.com/push-in/pam/discussions)

</div>

PAM (PHP, Always in Memory) keeps your PHP application in memory on a Rust and Tokio runtime and takes it to every target.

| [**PAM**](https://github.com/push-in/pam) | [**PAM Desktop**](https://github.com/push-in/pam-desktop) | [**PAM Native**](https://github.com/push-in/pam-native) |
| --- | --- | --- |
| The runtime and CLI: persistent PHP servers, Laravel, async I/O and WebSockets. | Native Linux, macOS and Windows apps written in PHP. | Real native Android and iOS apps in PHP: UIKit and Android Views, no JavaScript runtime. |

Install the CLI:

```sh
curl -fsSL https://github.com/push-in/pam/releases/latest/download/install.sh | sh
```
